# Prompt voor VS Code - Contact Page Toevoegen

Plak deze VOLLEDIGE prompt in Claude in VS Code:

---

## Task: Voeg Contact Page toe aan Histora repo

Ik wil een contact pagina (`contact.html`) toevoegen aan mijn GitHub repository `demore2/histora` in de `/public` folder.

### Wat je moet doen:

1. **Maak bestand aan:** `public/contact.html`
   - Dit is een HTML contact form voor account deletion requests
   - Moet geschikt zijn voor Google Play Store (gebruikers kunnen hun account verwijderen aanvragen)

2. **Content:**
   - Titel: "Histora Support"
   - Opties: Delete Account / Request My Data / Other Request
   - Velden: Email, User ID (optional), Message
   - Design: Groen (#163D31) en goud (#D6A84F) branding
   - Submit button stuurt request naar businessdemore@gmail.com
   - Responsive design (mobiel en desktop)

3. **Na aanmaken:**
   - Voeg het bestand toe naar `main` branch
   - Push naar GitHub
   - Vercel deployt automatisch

### Ik heb al een template:
Hier is een kant-en-klaar HTML bestand dat je kan gebruiken. Het ziet er professioneel uit met:
- Histora branding (groen/goud)
- Account deletion form
- Email validation
- Success message
- Responsive design

### Deliverables:
1. Contact pagina HTML bestand
2. Klaar om in `/public` folder te plaatsen
3. URL wordt: `https://historia-deploy-psi.vercel.app/public/contact.html`

---

**BELANGRIJK:** 

Het HTML bestand bestaat al, je hoeft het alleen maar:
1. In VS Code te openen (contact.html)

3. Committen met message: "Add account deletion contact page"
