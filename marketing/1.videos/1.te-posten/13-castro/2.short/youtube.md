## Hook-audit (viral-hooks + short-form-video, Reel: 2-secondengrens, beeld + tekst vanaf frame 0)

```
HOOK A: "What if you were Fidel Castro?" + teller "Ruled Cuba · 49 years"
  Delay:       pass — naam in de eerste woorden, beeld = Castro op het podium voor een mensenzee
  Confusion:   pass
  Irrelevance: pass — jij-vorm
  Disinterest: weak — de vraag zelf is het contrast; de teller (49 jaar) geeft de haak. Controle-variant.

HOOK B: "You're 32. You started with 82 men. Now you rule Cuba." (scène: op een tank Havana in)
  Delay:       pass — "32" + "rule Cuba" binnen 2 s, beeld = juichende straat, tank, vlaggen
  Confusion:   pass — drie korte zinnen
  Irrelevance: pass — jij-vorm, leeftijd van de kijker in de buurt
  Disinterest: pass — 82 man ↔ een heel land (hoe dan?), antwoord pas in de video (Granma, Sierra)

HOOK C: "The CIA planned to kill you with an exploding cigar." + teller "638 · claimed by Cuban intelligence"
  Delay:       pass — CIA + jij + sigaar in de eerste zin, beeld = Castro 's nachts met sigaar
  Confusion:   pass
  Irrelevance: pass — jij-vorm
  Disinterest: pass — absurd middel ↔ dodelijke bedoeling; "638" opent de vraag "en hij overleefde?"
  Voice:       zelfde cadans als Baldwin/Stalin-openers
```

## Slagingskans

**~25-30% kans op viral op IG** (≥ 10K). Waarom het kan werken: bekend + omstreden (de Stalin-les), concreet fanverzoek
met 11♥, en hook C (exploderende sigaar, 638) is het soort absurde feit dat gedeeld wordt. Waarom het kan floppen:
Castro is minder "groot" dan Stalin voor een jong publiek, en de blokfiguur moet zonder gezicht herkenbaar zijn (baard +
pet + sigaar doen dat werk). Verwachting per trial: 1-4K weergaven; de winnaar waarschijnlijk C of B.
